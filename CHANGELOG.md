# Changelog

## 0.1.0 — Public test release

This initial standalone Gen 1 test release adds Shedinja as species **#152** with Bug/Ghost typing, 1 base HP, a Pokédex entry, a small Gen 1-compatible move set, and transparent front/back battle sprites.

It also adds the persistent `WONDER GUARD` inventory item. While present, Wonder Guard blocks non-super-effective direct move damage only for the player’s active Shedinja. It does not protect other Pokémon, opposing Shedinja, status moves, or typeless self-damage such as confusion.

The release intentionally does not edit wild encounters, starters, gifts, maps, or story scripts. Use a compatible party/content editing tool to add Shedinja during testing.

This mod is intentionally incompatible with Crystal 251, Kanto Reforged, and every other mod that changes the Pokémon roster, Pokédex, dex data, or species indices.
